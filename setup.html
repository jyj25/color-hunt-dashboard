아두이노(UNO) 준비

  1. 아래 연결 표대로 LED 3개를 연결합니다 (USB는 분리한 상태로). 키패드는 쓰지 않습니다.
  2. Arduino IDE에서 RPS.ino 파일 하나를 RPS 폴더에 넣고 엽니다(폴더 이름과 파일 이름이 같아야 합니다). 추가 라이브러리는 필요 없습니다.
  3. 보드는 "Arduino Uno", 포트는 실제 COM(예: COM3)을 고르고 업로드합니다.
  4. 시리얼 모니터(115200, 줄 끝 "새 줄")에서 1 STATUS, 2 JUDGE 1 0(바위 vs 가위 → 이김, 초록 LED), 3 SIGNAL 0을 보내 LED가 켜지는지 확인한 뒤 시리얼 모니터를 닫습니다.
  5. 위의 UNO 연결을 눌러 포트를 선택하고, LED 시험 버튼으로 세 색이 켜지는지 확인합니다.

심판은 아두이노입니다. 웹이 두 손을 JUDGE 내손 상대손(가위0 바위1 보2, 내 손 3=못 냄)으로 보내면 보드가 승패를 계산해 LED를 켜고, 결과를 JSON으로 돌려줍니다. 🟢 초록 = 이김, 🟡 노랑 = 비김, 🔴 빨강 = 짐(시간 초과 포함). 라운드 중에는 모두 꺼져 있습니다.

LED 연결 (신호등 3개)

USB를 분리하고 연결하세요. LED는 긴 다리가 +, 짧은 다리가 −입니다. LED마다 저항(1kΩ)이 꼭 필요합니다.

현재 배선 (펌웨어 핀: 초록 D3, 노랑 D4, 빨강 D5)
LED의미LED − (짧은 다리)LED + (긴 다리)UNO 신호 핀
🟢 초록이김빵판 D6빵판 D7D3
🟡 노랑비김빵판 D13빵판 D14D4
🔴 빨강짐 · 시간 초과빵판 D21빵판 D22D5
  • UNO 신호 핀(D3·D4·D5)은 저항을 거쳐 각 LED의 + 쪽 줄(7, 14, 22번 줄)로 가야 합니다.
  • 각 LED의 − 쪽 줄(6, 13, 21번 줄)은 UNO GND로 이어져야 합니다.
  • UNO D0·D1(USB 통신 핀)은 비워 둡니다.

빵판은 같은 숫자 줄의 A~E 5칸, F~J 5칸이 각각 이어져 있습니다. 저항과 GND 선의 정확한 위치는 각자의 배선에 따라 다르므로, 위 세 가지 조건(신호→저항→+ / − → GND)을 확인하세요.
